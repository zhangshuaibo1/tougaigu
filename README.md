# 掀起你的头盖骨 · 给明天的一封信

原创 2D 横向叙事机关冒险。阿拾负责站稳、跳跃与压住机关；掀开头盖骨，让小光灵拾光飞出，穿过薄幕、收集记忆并解开诗灯。

- 游戏：https://zhangshuaibo1.github.io/tougaigu/
- 版本：15.0.0「苔灯站台 · 黄铜与暖光」
- 原生 JavaScript / Canvas，无运行时第三方依赖；原《再活一局》仍在 `survivor.html`。
- 企业版权、原地址、六章、十个节日、全部本地存档与奖励规则保留。

## v15：第一章美术与机关反馈

苔灯站台新增前后分层的站棚、釉绿屋面、铆钉、拱窗、石砖站台、木质踏台、黄铜包角与玻璃诗灯。远景比可操作地形低对比，踏台顶面仍与原碰撞面重合。屋面缓存为一张本地离屏 Canvas，不下载图片；云和节日蝙蝠仍按游戏的展示时钟运动。

铜踏板连接到闸门的可见导线与转臂。身体踩下，转臂抬起；离开踏板会回落；真正解开第一盏诗灯后才锁定开启。站房两扇暖窗分别响应对应的诗灯，第二盏不能冒充第一盏的进度。原有玩法条件不变。

阿拾使用同一套掀盖与扶盖骨架，细化骨骼明暗、衣服折面、皮邮包缝线、金属扣和鞋底。起跳收腿、步行抬脚与落地压缩跟随现有物理状态；拾光归位仍使用原来的真实轨迹。触屏提示去掉重复动作名称。

## 操作

身体用 A/D 或左右方向键移动，W/上/空格跳跃。E 掀盖或归位；拾光用方向键自由飞行，靠近诗灯后按 Q/空格解谜。身体靠近朋友按 Q 交谈；Escape 暂停。手机使用方向和动作按钮。

第一章的去程票是可选记忆。主线须点亮两盏诗灯，再让身体走进右端出口。借景小戏、失物招领与第三章借月追光仍可游玩。

## 运行与检查

```sh
python3 -m http.server 8080 --directory dist
npm test
npm run check
```

浏览器验证工具仅用于测试，不是游戏依赖：

```sh
python -m pip install playwright==1.55.0
python -m playwright install chromium
python scripts/browser-smoke.py --url http://127.0.0.1:8080/ --version 15.0.0 --output verification/browser
```

浏览器脚本通过真实键盘与模拟触摸进行操作，桌面从起点走到第一章出口，窄屏验证拾票、归位、暂停和布局。为可靠定位，测试会在浏览器内给 app 模块临时附加一个只读坐标查询，不修改游戏坐标、进度、奖励或解谜状态；生产文件没有该查询接口。物理手机性能不由这些测试代替。

## 源码与发布

`dist/dream-engine-base.js` 原样保留 v14 的物理与原场景实现。`dist/dream-engine.js` 是只增加第一章表现的薄子类：仍是同一实例、同一物理更新和一个动画循环。新绘制集中在 `dream-station-art.js`；其他五章与十个节日继续使用原表现。

`main` 保存源码、测试与文档；`gh-pages` 根目录只部署 `dist/` 内容并保留 `.nojekyll`。CI 不自动发布，只验证候选版本和实际公开页面。发布前需检查远端 SHA，禁止覆盖并发修改。

存档仍为当前浏览器本地存储，不是账号云同步。顶部设置可导出旅途备份。v15 不新增存档键、不迁移或清空旧进度，不增加奖励结算。

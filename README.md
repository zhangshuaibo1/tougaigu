# 掀起你的头盖骨 · 给明天的一封信

原创 2D 横向叙事机关冒险。阿拾负责站稳、跳跃与压住机关；掀开头盖骨，让小光灵拾光飞出，穿过薄幕、收集记忆并解开诗灯。

- 游戏：[掀起你的头盖骨](https://zhangshuaibo1.github.io/tougaigu/)
- 已发布并完成本轮验收：16.0.0「灯下的邮差」
- 原生 JavaScript / Canvas，无运行时第三方依赖；原《再活一局》仍在 `survivor.html`。
- 企业版权、原地址、六章、十个节日、全部本地存档与奖励规则保留。

## v16：精绘站房与邮差步态

第一章接入原创全景精绘：夜色站房、黄铜站钟、暖窗、釉绿屋面、远处树影与城市形成完整景深。生产资源为原尺寸 2172×724 WebP，266,328 字节；完整 PNG 原稿、生成提示与校验值一同保存。背景按 0.28 视差跟随镜头，开场桌面和窄屏都保留主站钟。加载或绘制失败时使用 v15 程序场景，游戏照常运行。

真实可操作的木踏台、石砖地面、铜踏板、导线转臂和玻璃诗灯仍由 Canvas 绘制，碰撞和机关条件不变。两扇站房窗继续分别响应对应的真实诗灯。谜灯加了克制的深色衬底与标牌，避免和背景站钟混在一起。绒绒的翼膜、衣料与灯笼照明也与站台协调。

阿拾的脚步现在分为支撑和摆动阶段，完整速度下支撑脚不会随身体滑移；鞋底补偿身体起伏与落地压缩，起跳收腿、下降伸脚。外套折面、围巾、皮邮包缝线和黄铜扣进一步细化。角色表现由已有速度与步态推导，原来的头盖、双手、拾光和手持物锚点保持一致。

三份入口统一生成资源版本映射，更新时将入口、样式与所有依赖模块一起切换到本版本。主线六章、十个节日、前两章车票/种子/纸盆与旧存档都保留。

## 操作

身体用 A/D 或左右方向键移动，W/上/空格跳跃。E 掀盖或归位；拾光用方向键自由飞行，靠近诗灯后按 Q/空格解谜。身体靠近朋友按 Q 交谈；Escape 暂停。手机使用方向和动作按钮。

第一章的去程票是可选记忆。主线须点亮两盏诗灯，再让身体走进右端出口。借景小戏、失物招领与第三章借月追光仍可游玩。

## 运行与检查

```sh
python3 -m http.server 8080 --directory dist
npm test
npm run check
```

每次更改 package 版本后运行 `npm run version:assets`，它同步三份入口的版本标记、模块映射和样式引用；`npm run check` 会检查过期映射和静态资源缺失。

浏览器验证工具仅用于测试，不是游戏依赖：

```sh
python -m pip install playwright==1.55.0
python -m playwright install chromium
python scripts/browser-smoke.py --url http://127.0.0.1:8080/ --version 16.0.0 --output verification/browser
```

浏览器脚本通过真实键盘与模拟触摸进行操作，桌面从起点走到第一章出口，窄屏验证拾票、归位、暂停和布局。为可靠定位，测试会在浏览器内给 app 模块临时附加一个只读坐标查询，不修改游戏坐标、进度、奖励或解谜状态；生产文件没有该查询接口。物理手机性能不由这些测试代替。

## 源码与发布

`dist/dream-engine-base.js` 原样保留 v14 的物理与原场景实现。`dist/dream-engine.js` 是只增加第一章表现的薄子类：仍是同一实例、同一物理更新和一个动画循环。站台绘制集中在 `dream-station-art.js`，邮差动作和材质在 `dream-traveler-art.js`，图片生命周期在 `dream-painted-scene.js`；其他五章与十个节日继续使用原表现。

`main` 保存源码、测试与文档；`gh-pages` 根目录只部署 `dist/` 内容并保留 `.nojekyll`。CI 不自动发布，只验证候选版本和实际公开页面。发布前需检查远端 SHA，禁止覆盖并发修改。

存档仍为当前浏览器本地存储，不是账号云同步。顶部设置可导出旅途备份。v16 不新增存档键、不迁移或清空旧进度，不增加奖励结算。

## 可以供司机使用的路线

### 入口与蓝页

出生点 `(105,560)` 已在 NPC 的交谈范围内。正常走到目标 x=120 后停稳，实际 x=118.779，y=560，`getStoryNPCView().near===true`；`interact()` 产生 `story-npc-3` 的真实对话暂停，`resolveTalk()` 恢复。NPC在 `(190,560)`，交谈判定为身体横向距离小于98、脚高距离小于90。

**不要为了截图走到 NPC 自身 x=190。**旧画面里角色会覆盖小鲸轮廓。左侧 x≈120 的交谈和实际掀盖画面能同时保留阿拾、拾光、头内小鲸和蓝页；它们是不同对象。基线：`lanye-near.png`、`lanye-talking.png`、`lanye-open.png`。对话 JSON 收到本局0灯的原台词；Canvas没有渲染网页对话框。

### 第一浮书：从地面可以正常登上

先以身体走到 x≈692.5（实际停在691.246），保持 y=560。只读等待 **`book-a.y>=478 && book-a.dy>0`**，即书接近低端且正在下降，再正常跳跃；不要只按固定墙钟延迟起跳。

本次起跳时游戏时间8.45，书 y=478.540、每步 dy=0.551；0.75游戏秒后身体真实落到书上：`platform==='book-a'`、y=491.964、x=691.246。它的可踩区为当前 `[615,770]`，不是一张固定高度的背景画。

落脚后释放所有方向输入 **453帧/7.55秒**，覆盖一个完整升降周期：书面 y 从368.000156到491.999958；每帧身体 grounded、platform正确，`abs(body.y-book.y)` 最大为0，身体相对书的 x 漂移为0。基线：`book-a-boarded.png`、`book-a-lower.png`、`book-a-upper.png`。

随后原地掀盖，身体继续由真实浮书承载。拾光依次飞近记忆 `(375,420)`、`(990,270)`，再到第一灯 `(835,205)` 共鸣；灯题正确答案是「更上一层楼」，原答案索引0。灯亮后读取 `barrierOpen(catalogue)===true`，再归位。

### 目录门与第二浮书

身体经已打开的 `(1180,390,38,170)` 目录门，到 x≈1245 地面取景，再走到第二浮书左侧目标 x=1440，实际停在1438.801。此位置离漂游影子的最左危险范围有余量；不要把本条0死亡结果扩大成书上任意 x 都同样安全。

等待 **`book-b.y>=473 && book-b.dy>0`**，正常跳跃。本次起跳时间32.9，书 y=473.240、dy=0.534；0.7333秒后落到 y=486.778，`platform==='book-b'`。书的当前可踩区为 `[1410,1580]`。

释放方向输入 **512帧/8.533秒**，覆盖完整升降周期：书面 y 从343.000854到486.999978；附着无丢失，脚高误差0、相对x漂移0。基线：`book-b-boarded.png`、`book-b-lower.png`、`book-b-upper.png`。不需要新增跳跃高度、改变相位或修改关卡才能上书。

### 风廊、第二灯与安全经过影子

从第二浮书掀盖，经 `(1590,320)` 飞向第二灯 `(1830,200)`，正常输入向右/向下抵消原风廊的左上推力。风廊边界 `(1350,95,590,370)`，力 `(-48,-100)`；灯共鸣半径是102，浏览器无需追求与灯坐标完全重合。第二题正确答案「一枚书签」，原答案索引1。

双灯后，仍让身体留在书的左侧。拾光飞到约 `(1600,410)`，正常脉冲使附近真实 drifter 冻结4.5秒；随后立即归位、带身体走到 x≈1750。实际冻结瞬间影子在 `(1521.383,507.468)`，身体通过到 x=1748.840时冻结还剩1.817秒。没有通过改 `hazard.frozen` 或关闭危险物来通过。

浏览器适配要把“冻结→归位→走过危险范围”当成连续动作。**不要在冻结后插入 HUD/AX 全量采样、网络等待或耗时截图来消耗4.5秒窗口。**这条离线路线的PNG编码不推进模拟时间，不能把它原样当作浏览器等待预算。可以在冻结前取景，在安全右侧再采完整证据。

### 第三记忆与真实出口

身体走到 x≈2010，掀盖让拾光靠近 `(2060,390)` 收下第三页记忆，再归位。身体到 x≈2130时可保存出口接近画面；继续正常向右，本次在 **x=2145.264、y=560** 自动完成一次。

出口锚点是 `(2195,560)`，原触发条件为身体形态、两灯齐、横向距离小于52且脚高距离小于90。因此身体在2145附近完成是原本真实出口范围，不应强迫它先到精确 x=2195 才算成功。本章记忆不是出口硬门槛；本路线收齐3页是为了留完整基线，未新增限制。

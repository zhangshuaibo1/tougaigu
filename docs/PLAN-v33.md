# v33：小旅伴·抬头等你

## 玩家体验

让原来的苔绿色小猫更像一位在旁陪伴的伙伴：浅色口鼻、独立双爪、耳内和尾缘更清楚，眼睛与头部会朝向真正显示的拾光。拾光飞回阿拾头盖时，小猫继续跟随它的归位轨迹，落入盖内后轻轻眨眼。

保持既有跟随位置、体量、阴影、开心语义和玩家操作。新增表现读取原头盖阶段和原时间，不建立额外计时器，不新增收集、奖励、存档字段或按键。减少动态时不播放新增摆动；特殊活动继续使用原绘制。

## 具体实现

新增纯视图／绘制模块 `dream-companion-art.js`，在 `dream-engine.js` 薄子类接入。render 作用域复用 base 已算出的同一个 presentedSoul 对象，finally 恢复；独立画猫调用安全回退，不能再次求姿态。`dream-engine-base.js` 原字节不变。

准确预研增量及历史原证据见 [预研说明](v33-prestudy/README.md)。正式准备从 v32 修正候选 ce412 出发，仅应用七项准确预研增量，再统一 33.0.0 版本并在完整 smoke 末尾接入三尺寸专项检查；不以旧预研整树覆盖新历史。

# v27 生产代码的离线验收

本目录验证工作区中的 **27.0.0 生产实现**，使用真实 `@napi-rs/canvas` 和 `dist/assets/coast-painted-v27.webp`。`verification-summary.json` 记录最终生产文件哈希；其中 `dream-coast-scene.js` 的 SHA-256 为 `5927d816f86835dbbf9e5d0237a251ed14953f11a80869609b43d30727257fc7`，已包含远岸右侧对齐、第一光区位置调整和浮点边界 clamp 修正。

最后一次复跑还包含归先生怀表随实际开合量连续抬落的修正；`dream-encounter-art.js` 的 SHA-256 为 `5be256ba3df0332e583661241b108dd6da182f32628c3f33bf04f5d6ac555ee4`。本目录的六条海岸路线、六组回音、第四章完整路线及蓝页像素测量均已用这个最终实现重新执行。

所有场景入口均明确是离线夹具。第五章使用 `start({chapterIndex:4,...})`，第四章使用 `chapterIndex:3`；之后通过公开输入、脉冲、解谜和归位接口前进，没有改坐标、灯、危险物计时、冻结值或存档。选择 `release` / `hold` 作为进入场景的已知选项，不能据此声称浏览器正常解锁或日记点击已验收。

## 第五章完整路线

三种原尺寸 Canvas（1100×640、390×595、320×431）各执行两条完整路线：实际生产 WebP 成功加载的 `release` 路线，以及本章画作 loader 明确拒绝的 `hold` 回退路线。共 **6 条**，全部通过。

每条均逐条重放 `docs/v27-baseline` 保存的 **2537 条** v26 输入/更新调用，并完成：

- **1285 个固定更新步**，模拟时间 `21.416666666666732` 秒。
- 每步整合引擎物理状态与 `BaseGame` 精确一致，同时与冻结的 v26 逐步记录精确一致。
- **220 条回调**与基础引擎及原始回调流一致，包括记忆、谜灯、检查点、结算和 cap 事件；原始双方回调全部保留。
- HUD 多出的 `clockEcho` 是预期展示字段，仅这个字段从事件等价比较中剔除。没有放宽游戏事件、物理、能量或结算比较。
- 两灯、三个记忆、三个钟摆通过、身体出口、零死亡，一次 3 星结算。
- 每个引擎实例只尝试加载一次海岸画作；失败稳定停留在原有程序绘制回退，不阻止完整通关。

`*-report.json` 保存完整回调和路线节点；`*-physics.jsonl.gz` 保存每个更新步的整合/基础引擎状态、能量、危险物、回音与灯状态，以及相对 v26 的一致性。报告同时记录压缩与未压缩内容的 SHA-256。

**回退的范围是离线真实生产 loader 拒绝。** 这不是浏览器的 `requestfailed`、延迟网络或 decode 路由测试；这些由浏览器 CI 另行验证。

## 两种回音及真实头内显示

- 中段通过实际引擎更新达到约 0.8 秒，再正常暂停；继续送入 **180 次更新**，完整 Canvas 像素、物理和回音状态均保持一致。
- 恢复后自然结束；同一 run 再掀盖不重播。

## 数字方向策略检查

`verify-digital-coast.mjs` 从冻结 v26 输入正常走到第一次真实脉冲，再使用 `browser-smoke.py` 的单轴预测控制策略模拟后续路径。理想 30 毫秒采样下，两个冻结点之间飞行 **1.25 秒**；越过第一危险完整右界时剩 **1.2667 秒**冻结，第二剩 **1.25 秒**。60/90 毫秒采样敏感性结果也保留在 `digital-coast-report.json`。

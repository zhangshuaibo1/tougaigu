# v24 接续：绒绒·请你上场

这是v23期间依据现有源码形成的下一轮美术计划，尚未实现。先读取最新main、QA和在途分支，收尾v23实际候选/公网验收，不建立竞争版本。

## 选择依据

第三章已经有精绘绒幕、铜件、木质舞台与精修拾光，但`dream-encounter-art.js`中绒绒的精修材质仍由`lighting === 'painted-station' && chapterIndex === 0`限定。第三章`story-npc-2`在(190,560)，道具为`theatre-ticket`，继续使用较平的翅膀、脸部、外套与票张绘制。其既有对白包括“鼻孔不售票”，可以用真实掀盖反应强化角色幽默。

现有公开截图主要覆盖跨台与双灯，没有足够近的绒绒样本。下一轮先正常进入第三章、走近角色，保存桌面/390/320原尺寸基线，确认实际差距后实现。

## 一组完整可玩改进

1. 保留奶油色绒毛、圆眼镜、淡紫外套和原轮廓。用少量清楚的明暗面表现绒翅厚薄、脸颊/袖口体积与克制黄铜反光；优先让正常游戏尺寸的眼睛和手部清晰，不以放大才能看到的装饰代替效果。
2. 保留三张剧场票，增加纸张厚边、月牙印记、切口和前后遮挡。票扇、手掌与手腕使用共同变换及握持锚点，抬起或展开时不滑手。票仍是NPC道具，不新增拾取、库存或通关条件。
3. 近处真实掀盖时，绒绒抬眼看向头盖，再以票扇轻轻指向舞台；扣盖后自然收回。未点灯、单灯、双灯对应候场、邀请、笑眼收票的细微姿态，读取当前真实灯状态，不从历史收藏冒领进度。沿用既有分阶段对白，不另加HUD、弹窗或虚构故事选择。

## 实现与验收边界

- 主要修改`dist/dream-encounter-art.js`中仅限`chapterIndex === 2 && prop === 'theatre-ticket'`的分支。若过渡需要，`dream-engine.js`可为NPC视图追加现有`theatreLight.amounts`，沿用现有时钟，不增加独立动画循环。
- `dream-encounters.js`和`dream-story.js`提供叙事依据；保持NPC位置、交谈半径、碰撞、存档和奖励。第一章、温室及后三章NPC绘制保持原范围。
- 绘制遵守现有`STORY_NPC_BOUNDS`，输入对象和Canvas状态不改变；票与手的握持关系、视线和离远后的收势有回归证据。
- 正常操作走近、掀盖、扣盖，观察0/任意单灯/双灯对应姿态；暂停像素一致，减动静态，不新增奖励或“已谢幕”状态。
- 离线绘制可覆盖姿态/材质/边界，真实候选与公网补正常进入第三章的近景截图和交谈操作。320/390是模拟触摸时明确标注，未做实机/Safari不得声称已验证。

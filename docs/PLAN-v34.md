# v34：近身抬盖，留一点画面

## 玩家能看到的变化

在手机上让阿拾掀盖、拾光在身边飞行时，帽沿、握盖的手和拾光尽量一起留在画面里。角色与道具仍使用真实世界位置，整幅场景沿同一镜头平滑移动。拾光飞远后继续原来的探索跟随，回到身体附近再自然恢复近身构图。

本轮解决的是窄屏边缘裁切，不增加操作、剧情等待或奖励。沿用阿拾、拾光、小旅伴与六章原创美术，保持原物理、碰撞、存档、机关和输入。

## 实现边界

- 仅普通主线六章、画布 CSS 宽度不超过480px、真实开盖／全开／归位阶段启用；桌面与特殊活动继续原路径。
- 读取同帧的原角色姿态、头盖状态与实际显示的拾光，计算身体、头、帽盖、手及拾光的保守实体包围，不把发光和粒子当作必须容纳的实体。
- 在世界边界内求能同时容纳实体与约8 CSS px留边的相机区间。身体中心仍在视口内、区间可行且空间足够时才进入；使用24／8 CSS px几何余量滞回，避免临界处反复切换。
- 原相机跟随仍先运行；按原固定步的衰减预算，在绘制前统一得到一个最终camera。背景、世界、剔除、角色与导航共同使用它，不能临时偏移角色或在绘制后偷偷恢复相机。
- 沿用原平滑速度；约8px是稳定近身构图目标，不声称所有过渡帧都立即达到。暂停冻结，暂停中resize的第一帧使用统一新投影，减少动态即时呈现。

准确源码与两次真实预研失败、诊断和修复见 [预研归档](v34-prestudy/README.md)。该研究仍标33.0.0，不能冒充本轮正式34结果。

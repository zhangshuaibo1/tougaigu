# v32：给对白留一点空地

## 玩家体验

桌面普通故事中，角色对白与目标提示曾在左侧叠放，温室越根后会遮住阿拾的面部与脚边。v32 把这两类信息分到画面左右：左侧保留人物对白，右侧容纳目标、附近动作和短公告。玩家可以读到当下的对话，同时看清角色与可行走区域。

本轮只调整两个布局样式和两份同内容入口 HTML。画布、控制按钮、原对白内容与计时、剧情头像、辅助阅读语义、物理和存档保持原规则。宽度小于 900px 时保留旧布局；节日、失物调查与月下小剧场使用原来的特殊布局。

## 已完成的本地实施

- 用一个中性容器承接原有对白与提示元素，保留它们的 ID、内容及事件。
- 在至少 900px 的普通故事中使用左右两列，HUD 保持独立整行。
- 增加只读布局观测与六个独立视口／减动配置；所有原有六章、手机、结局与网络错误门槛继续执行。
- 测试夹具保存准确 v31 的两份 CSS，用已加载样式表的同步开关完成对照，并在 finally 中恢复。最初异步样式恢复导致的测试失败保留在原证据中。

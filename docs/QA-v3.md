# v3 四季来信与时光礼物验收

日期：2026-10-28。版本：3.0.0。

## 功能范围

10个节日故事与独立关卡、20道新谜题、30份任务礼物、10件纪念物、11套可永久解锁的装扮（10节日+晨星）、34幅原创SVG、原生Canvas角色与天气动画。平日累计奖励、每年每节日见面礼、节日阶梯奖励、持续旅途补给、星砂兑换与三个实际消耗品。保留六章主线、原生存游戏、原存档和企业信息。

## 自动化验证

`npm run check` 检查13个JavaScript模块及全部本地HTML/ES模块引用；`npm test`的7个测试文件全部通过。原54项回归保留，新增17项节日引擎、23项日历/内容/存档、27项奖励测试，共121个场景。

- 六个主线和十个节日关卡均通过真实移动、跳跃、飞行输入完成路线，无传送替代路线测试。节日必须两灯和三礼物全部满足才可退出；主线记忆仍可选收。
- NPC与谜题暂停有独立的resolve握手，普通resume无法绕过。罗盘计时只在游戏推进时减少，轻羽抵消一次跌落计数，满灵光拒绝糖果消费。
- 日历按上海时区验证活动边界、跨年、春节和情人节重叠、闰月排除。2025—2035农历依照香港天文台月首锚点校正；2027春节包含专门回归。
- 奖励覆盖首采样、异常时间跳跃、暂停/隐藏、跨会话、普通双标签计时租约、重复领奖、往期补领、持续补给、存档清洗、兑换与效果成功才扣库存。
- 新增道具事务同步重入回归：引擎useItem同步发HUD时，库存仍正确扣除并保存，同时保留合法新增时长，嵌套交易被拒绝。
- 默认index.html与dream.html逐字一致，dream-app静态DOM选择器无缺失节点。

## 真实边界

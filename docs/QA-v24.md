## 实际改动范围

### 来信头像与当前说话人同步

新增[`dream-story-portrait.js`](../dist/dream-story-portrait.js)。每次换页先同步隐藏旧头像，再设置新的资源和替代文字；加载及解码完成、当前请求仍与本页匹配时才显示图片。控制器使用递增修订号，避免旧异步结果覆盖后来的页面；正常结束或跳过故事时取消旧请求的显示资格。失败时保留中性星形占位，台词与翻页按钮的流程不由图片控制器接管。

`dream-app.js`只在既有`renderStoryLine()`和`finishStory()`中接入该控制器，`cap-portraits.css`提供隐藏旧图和占位样式。未修改第三章三页台词、说话人、故事选择、章节结算或奖励。

### 剧场绒绒的材质和动作

[`dream-encounter-art.js`](../dist/dream-encounter-art.js)为第三章`moth / theatre-ticket`视图启用脸部、绒翅和外套的明暗材质，补充袖口、边缘反光和脸颊细节。三张票增加纸边、切口、月牙印记和压边；票扇和指尖在同一个握持变换中绘制。近处掀盖时，票扇随真实`capOpen`抬起、倾斜并略微展开，视线上移；真实当前谜灯数影响轻微姿态，双灯时使用笑眼。没有新增拾取物、库存项目、通关条件或独立动画循环。

主要新增分支限于第三章，但不能声称其他章节每个像素都未变化：新加的一条绒翅边缘描线位于共用`pose.painted`分支，第一章精绘绒绒也会受到这一细节影响。基础引擎、物理、关卡、NPC位置与交谈数据、故事正文、存档和奖励模块在本轮提交中没有改动。NPC仍位于第三章原有的(190,560)，三张票仍是道具。

## 首次候选失败与定向修正

首次候选40837782352的`verify`工作日志（job `123326548851`）明确记录：553项逻辑测试通过，随后浏览器在`exercise_theatre`第1033行执行`toggle(page, True)`，进入`Locator.tap()`后失败：

```text
Locator.tap: The page does not support tap. Use hasTouch context option to enable touch support.
```

该操作发生在正常桌面通关并重访第三章后，首次390px绒绒掀盖采样。脚本此前通过CDP开启触摸模拟并调整了视口，但原浏览器上下文是桌面上下文；新增代码误用了要求`hasTouch`上下文的Playwright `tap()`。错误不能解释为NPC、图片、碰撞或存档故障，整轮也不能记为成功。

提交d9c6bdb只将此处掀盖和归位两次调用改为已有的`tap_control(page, '#stage-toggle')`，让它们像同一路线的暂停、重新开始和方向控制一样发送真实CDP触摸输入；没有注入游戏状态，没有降低玩法断言，也没有为了绕过错误改运行时。随后修正候选40838159705完整通过，main与公网40838885102再次通过。

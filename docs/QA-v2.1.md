- 根入口 `index.html` 直接进入《掀起你的头盖骨》，`dream.html` 保留为兼容入口，两份 HTML 内容一致。
- 原版生存游戏迁至 `survivor.html`，进入即开局。两款游戏通过同一套顶部悬浮菜单切换。
- 移除营销首页、宣传模块和开始前强制对白。章节地图、可选来信、档案、帮助、设置按需打开；故事、谜题、收藏与结局仍保留。
- 角色摘要与档案使用真实本地存档；身体与拾光切换时同步角色名和头像。
- 公司名称、统一社会信用代码、原始本地 Logo 与官网链接保留在页面底部。
- 手机操作区为角色画面让出空间；安全区域同时计入导航、场景和页脚偏移。

## 实际浏览器验收

### 直接进入与菜单

- 桌面 `index.html` 与 `dream.html` 进入实际场景，没有营销首页或阻塞开场对白。已有进度进入倒流温室，保留 1 / 6 章、1 / 18 记忆。
- 打开帮助后对比 HUD 时间保持不变；关闭帮助后可以继续操作。
- 手动暂停 → 地图 → 关闭，重新显示暂停窗口；再次从地图继续可回到同一关卡。
- 顶部切换菜单可从新冒险进入原版，再返回默认新冒险入口，两条路径均无需开始页。
- 原版仍显示此前的 2 骨片、厚实骨架 1 级，常规开局生命为 118；打开备战与切换工坊不会增加骨片。
- 在备战选择每日试炼，当前局仍显示墓园冒险；明确点击“结算本局并开始”后，进入每日试炼，初始生命为无永久加成的 110。
- 新冒险设置中实际导出当前备份并再次导入；确认后旧运行实例被替换，关闭设置进入有效保存章节，计时重新从 00:00 开始，已完成章节与记忆保持。

### 390 × 844 手机布局

- 两款页面的内容宽度与滚动宽度均为 390px，没有横向溢出。
- 浮动导航、章节/战斗数据、触屏控制和企业页脚同时可见；梦境角色不再被方向按钮盖住。
- 实际点击掀盖按钮，从阿拾切换到拾光；顶部头像、角色名和动作按钮随之更新。
- 按住方向按钮后，拾光在场景中移动；档案可打开真实收藏数据。
- 档案 → 已解锁记忆残页 → 返回档案的过程中，HUD 时间持续保持 00:38。
- 手机档案弹窗内容宽度与滚动宽度均为 344px，长内容通过竖向滚动访问。
- `game-first-mobile.jpg` 为真实 390px iframe 操作截图。

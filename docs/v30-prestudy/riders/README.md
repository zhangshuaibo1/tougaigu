# 浮书与树根 · 原尺寸 Canvas 预研证据

**范围：独立本地预研，未发布，尚非浏览器或实体手机证据。** 使用当前产品 `DreamGame` 的生产 Canvas 绘制，在直接起章的离线夹具中，从作者出生点只通过原控制方法走到实际书面、蘑菇与树根。没有赋值身体坐标、platform、grounded、能量、灯、完成状态或时钟。

## 已实际运行的范围

`scripts/render-v30-riders.mjs` 在 **390×595 与 320×431** 各走一条图书馆路线和一条邮局路线。两种尺寸均覆盖：

- book-a / book-b 各完整纵向周期，真实 dy 上、下行各一张关键帧；取本步 `abs(dy) > 0.75` 的实际帧，以便观察细微腕部变化。
- last-stage 完整横向往返，真实 dx 左、右行各一张关键帧。
- 踩实际蘑菇得到 `vy=-850`，正常控制身体落上 `y=390` 根台，捕获第一次真实接触 `landingAge=0`。
- 纵书和横书上的正常开盖、归位接住，实际检查左手握盖与右手接住/扣盖的优先级。

共 **4 条离线路线、7,088 次同输入候选物理对照**，其中 7,004 次推进、84 次暂停 update；**14 张核心帧 + 8 张握盖/接住帧**，每张都有同物理帧的展示层关闭对照，共生成 44 张原 PNG。两种宽度的同章节输入 tape 哈希相同。

## 对照是怎样产生的

对同一实例临时关闭 `getTravelerPerformanceView()`，绘制后在 `finally` 恢复原方法。没有修改运行时源码或物理状态。每张关闭对照还与独立、未修改的 v29 候选 `bfe9fd55400c89a06c5f0b677cf02a6380e0a624` 的同输入实例比较：**22 组均逐像素相等**。

新画面相对上述对照的差分全部位于原人物包围范围，**包围外差分为 0**；14 张核心帧在原尺寸下改变 194–781 个像素。这是人物姿态差分的测量，不代表对整体美术品质的评分。原尺寸审阅可以看清书面接触、手臂伸展和根台着地；纵书上下行的腕部方向调整仍是细微变化，不应夸大成大幅动作。

14 个关键位置各暂停并完成 6 次 update/render 检查，完整 Canvas、身体、rig 与 view 均冻结。这是离线调用机会，不是实测浏览器 RAF。

## 归档与审阅

本目录只归档 **8 张未经缩放、拼接、修图的原 PNG**：390 的 book-a 上下行及一张同帧关闭对照，320 的 book-b 上下行和邮局横书左右行，以及 390 的根台首次落地。完整报告保留两种尺寸的所有帧、姿态、支撑面、原图哈希、源码哈希、暂停结果和路线计数，其余 PNG 位于本次 `/tmp/tougaigu-v30-riders` 输出目录，可用脚本重现。

22 张新画面均已按原尺寸查看；调整纵书取帧条件后，其 8 张新关键图与归档的同帧关闭对照已再次查看。没有把数值检查当作图审，也没有声称人工逐张看过全部 22 张关闭对照。`selection-manifest.json` 明列已查看和已归档的文件。

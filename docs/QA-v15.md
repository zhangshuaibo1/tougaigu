# v15 苔灯站台 · 黄铜与暖光

日期：2026-10-28（洛杉矶）。版本：15.0.0。承接 `44d7c031` 的 v14 功能代码和独立分支的续行检查点。

## 已实现

第一章分层站棚、釉绿屋面与铆钉、拱窗、暖色木踏台、黄铜包角、石砖地面、玻璃诗灯；可操作地形轮廓与原碰撞面保持一致。真实踩踏板驱动闸门导线和转臂，离开会复位，第一盏诗灯点亮后才锁定。站房左右窗分别响应第一、第二盏实际诗灯。

阿拾的皮邮包、骨骼、衣服、围巾与鞋加入材质层次；踏步和收腿来自原步行动作与垂直速度，手与盖沿仍共用同一骨架。暂停冻结，减少动态停止背景动画并直接落定信号。触屏操作提示去掉重复动作词。

`dream-engine-base.js` 与原 v14 `dream-engine.js` 字节相同。新的 `dream-engine.js` 只覆写第一章绘制和非持久表现状态；原固定步长、计时、物理、谜题、存档、奖励和动画循环仍由原引擎执行。其他五章、十个节日的绘制序列逐一与基线对比。

## 仍需提升

本轮是原生 Canvas 美术样板，不是已经达到成熟商业游戏的最终美术。大块站房造型、NPC 与主角材质协调、动作的预备/缓冲、桌面地面提示密度仍有提升空间；其余章节尚未推广本轮美术。没有物理 iPhone/Android、Safari 或低端手机 GPU 实测。不能以托管 Chromium 的帧间隔替代真实设备性能结论。

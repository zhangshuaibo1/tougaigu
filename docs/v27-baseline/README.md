## 文件内容

每个尺寸目录包含：

- `route-report.json`：范围声明、源代码哈希、完整回调、路径动作、谜题适配、三摆冻结与越界状态、截图清单及结算。
- `physics-trace.jsonl.gz`：每个固定更新步与非方向动作的整合/基础引擎完整物理状态、能量、危险物、输入及事件比较位置。解压后是逐行 JSON，未删掉重复的基础引擎证据。
- `input-tape.json`：全部 2537 条相同公开方法/更新调用，可核对具体输入序列。
- 14 张原尺寸 PNG，包括入口、归先生、风区及第二记忆、三个冻结钟摆、三摆通过、双灯出口和完成帧。图片没有缩放、合成或重绘加工。

`baseline-summary.json` 保存三种尺寸统计、跨尺寸输入一致结果、全部源代码哈希和交付文件大小/SHA-256。报告中的哈希同时覆盖原始逐步数据和压缩文件。

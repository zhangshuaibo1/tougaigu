# v25 阿拾·稳稳落脚

基线为已发布v24源码d9c6bdb279f3bb42f04e23d5bf55d34a90fb9097。v24公网证据已在5c0fbe7归档；本轮候选分支为`iteration-v25-ashi-performance-20261029`。本页记录范围与验收目标，实际完成情况以QA-v25为准。

## 这一轮让角色动作更清楚

第三章已有精绘剧场、绒绒、拾光、真实跨台谢幕，以及阿拾的骨质、衣料、围巾、邮包和速度驱动腿姿。当前空中双手仍接近普通站立，随台搬运时也没有独立的平衡轮廓；基础落地压缩最大约79ms。因而这轮先在第三章形成可复用的身体动作样板，而不是重新生成已完成背景。

- 上升时自由手臂轻收抬起，下降时略展开，以轮廓表达动作；跳跃输入和物理立即生效，不人为加等待。
- 只在真实腾空后接触可站立表面时，形成约0.2秒的承重收势，衣摆和邮包有小幅跟随。重生、护符救回、重开、灵魂状态落地不冒充成功落脚。
- 真正附着第三章移动舞台并核实脚高和水平重叠时，停步后的自由手臂略作平衡。舞台位移不冒充走路步频，不增设通关、奖励或提示状态。
- 头盖抓握、接回拾光、头内遮挡使用原来的统一角色rig。未占用的手部才表演，原物理身体和站立鞋底保持对应。

## 实现边界

仅第三章故事模式启用。表现模块从原更新循环取得真实物理采样及visualTime，不新建计时器或RAF，不改变基础引擎、平台几何、碰撞、跳跃、能量、存档、故事和奖励。暂停冻结；减动使新增装饰动作收稳，恢复动效不补播旧落地。

## 验收目标

1. 用相同真实输入并行运行原基础引擎与新引擎，比较身体、平台、能量及结算关键状态。包含正常跳跃、真实登台/乘台/下台、有无轻羽护符的跌落恢复，覆盖原生输入而非只用设置坐标的姿态替身。
2. 对上升、下降、落地、乘台、掀盖和回盖取正常比例离线生产Canvas画面，并明确这些是引擎绘制证据，不是浏览器或实体设备。
3. 原有真实浏览器路线保留前两章、第三章双灯与出口、三页来信、一次结算、第四章解锁、320/390模拟触摸首台和资源回退。新增只读角色姿态观测，正常暂停/设置操作验证冻结及减动；不写入位置、存档或解锁状态。
4. 补v24头像网络延迟场景：在正常来信界面延迟指定图片，检查新台词出现时旧人物不可见，释放后正确解码；快速翻页及加载中Escape关闭后重开不被旧结果覆盖。失败资源的台词仍可读、可继续。条件触发释放，不能靠固定等待使截图碰巧正确。
5. 通过候选CI后部署原地址，再验证源码dist与Pages每个运行文件一致、公网版本和关键操作。最终截图保留原图，明确模拟触摸、实体手机及Safari的证据边界。
